Wiki Springfield


Descripción


Wiki Springfield es un sitio web estático dedicado a la ciudad de Springfield y algunos de sus personajes más representativos de la familia Simpson. El proyecto está diseñado como una mini enciclopedia visual que muestra contenido organizado en páginas individuales, incluyendo biografías y datos relevantes del personaje principal.

Esta aplicación se construyó con HTML y CSS, con una estructura simple y navegación clara para facilitar el acceso a las páginas internas. Es ideal como proyecto de demostración de una web estática, con diseño responsive mínimo gracias a Bootstrap.
Tecnologías utilizadas
🧩 HTML5
🎨 CSS3
⚡ Bootstrap 5
📁 Archivos estáticos (HTML/CSS/Imágenes)
Instalación
Clona o descarga el repositorio localmente.
Abre la carpeta del proyecto wikiSpringfield.
Abre el archivo index.html en tu navegador web favorito.
No se requieren herramientas adicionales ni instalación de dependencias para ejecutar el sitio.

Uso
Navega desde la página principal index.html.
Usa el menú de navegación para acceder a:
pages/homero.html
pages/familiasimpson.html
Explora las tarjetas e imágenes de personajes para ver información y enlaces disponibles.
Características principales
✅ Sitio web estático con navegación entre páginas
✅ Diseño limpio y consistente con Bootstrap
